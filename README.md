# SDP-applications-beyond-physics
Code for my bachelor thesis SDP applications beyond physics. Where I explore and compare applications of Semi-Definite Programming in Phyisics and beyond.

Matrix Completion are python codes and jupyter notebook that try to complete the entries of a Matrix M when we only know a set of their entries, knowing that it has the minimum rank possible. The most important library to use in these codes is cvxpy, necessary to solve SDP problems.

In Portfolio optimization one can find matlab codes that are available to solve Worst-case value-at-risk problems in the context of portfolio optimization, i.e. finding the investing portfolio that, with a lower risk give us the highest return.
